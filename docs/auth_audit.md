Scope: `backend/` (REST `app.main:app`, MCP `app.mcp_server.server`, ingestion worker `app.ingestion.worker`, SQL in `backend/db`).
Baseline: `pytest tests/test_supabase_auth_dependency_offline.py tests/test_phase1_security_boundaries_offline.py tests/test_phase2_authorization_offline.py tests/test_runtime_guard_offline.py` → 59 passed.

## Additional finding

`Settings.assert_production_config` compared the upper-case `environment` property to lower-case `"production"`, so the production CORS/FRONTEND_ORIGIN check **never ran**. Fixed (`app/config.py`), regression test `test_settings_production_config_check_is_no_longer_dead_code`.
