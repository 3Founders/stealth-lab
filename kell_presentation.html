The product

A procedure is an HTN, written in natural language.

A compound task decomposes into methods. A method decomposes into subtasks. A subtask calls a tool. Each element can be checked and priced on its own.

01

Task

“Create a NeurIPS-format report from this project.”

02

Method

Distill the sources, draft the sections, render the PDF.

03

Subtask

Search the literature. Write the abstract. Compile LaTeX.

04

Tool

Exa, a model call, a LaTeX compiler, a storage write.

05

Check

The condition the step must meet before the next one starts.

First principles: break the task into elements, then check and price each element.

Business model

Market

Every task a team repeats is a procedure someone can sell.

The supply is the people who already do the work: the analyst, the auditor, the release engineer. A procedure lets someone in Kanpur sell work to a buyer in San Francisco without moving.

Paid on verification

The verification is the receipt.

A run that completes pays. A run that fails releases the purchase. The author is paid for a task that worked, not for a listing.
