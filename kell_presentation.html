A better coding agent starts with a proven plan.

Small tasks go to cheap models. Hard reasoning stays with the best.

For incubator and department teams · October 2026

The problem

One premium model does everything, and forgets what worked.

Every task starts from zero

The agent re-invents the approach each time, even for work that has been done well before.

Small jobs use the dearest model

Summaries, reformatting and first drafts are paid for at the price of the hardest reasoning.

No record of what passed

Nobody can say which approach actually worked, so good methods are not reused.

How it works

Find a proven way, hand off the small parts, check the result.

1

Find

The agent asks the library for a proven way to do this kind of task.

find_ways(task)

2

Hand off

Small sub-tasks go to a cheap open model. Hard reasoning stays put.

call_model(glm-5.3-flash)

3

Check

The result is checked before it is used, and the outcome is recorded.

report_result(passed)

The global library

Ways that worked, with the receipts to show it.

Claims

Small statements, each with its source and when it was true.

Procedures

Step-by-step ways built from those claims, with conditions for when they apply.

Evidence

Every reuse records pass or fail. A way that stops working loses trust and is retired.

Anyone can read it. Publishing is a deliberate act, tied to a named person.
