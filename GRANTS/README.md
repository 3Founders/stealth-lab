# GRANTS — application pipeline

- `MASTER_PROFILE.md` — single source of truth. Update here first.
- `answer_bank.md` — reusable answers keyed by question; grows after every application.
- `applications/<program-slug>/draft.md` — generated drafts + human-only checklists.
- `discovery_log.md` — dated sweep findings (deltas only).

Usage: say **"apply to <program>"** (runs the grant-apply skill) or **"sweep grants"** for a source sweep.
Tracker of record: `../FUNDING_APPLICATIONS.md`.
