# Coding agents and AI-assisted IDEs: free tiers and free allowances (September 2026)

**Researcher check date: 2026-09-28.** Every URL below was fetched on that date unless otherwise noted. Anything I could not read on the tool's own page is marked **unverified**.

**Critical framing note for the report writer.** The category has bifurcated in the last ~12 months. (a) *Vendor-hosted free tiers* now almost universally meter in either credits/requests or workload units rather than advertising a request count, and several publish no number at all. (b) *Open-source / BYOK agents* (Cline, Kilo Code, Aider, Continue, Crush, opencode, Goose, Qwen Code, Zed's agent) are free software whose cost is whatever model you point them at — which makes "a free lab or gateway key turns a paid agent into a free agent" the single most important line in this report. Do not conflate the two.

## 1. Which coding agents are genuinely free ongoing, which are trials, which are paid-only?

### Takeaway
Only four tools publish a hard, readable free cap that includes real agentic capability: **GitHub Copilot Free (2,000 completions + 50 chat requests/month, agents "Limited"), Gemini Code Assist individual (1,500 requests/user/day), Google Antigravity Individual ($0, weekly-refreshing quota, no published number), and Trae Free ($3 of monthly usage)**. **Claude Code is not available on any free plan.** Cursor Hobby, Windsurf Free, v0 Free, Replit Free Mode, Lovable Free, Bolt Free, Warp Free, and JetBrains AI are free-but-throttled or credit-starved. Everything in the open-source/BYOK column is free software with no free inference attached unless your key is free.

### Inferences
- The **only** free tier that is both (a) a real agent (edits files, runs commands) and (b) large enough for all-day use with a published cap is **Gemini Code Assist individual / Gemini CLI at 1,500 requests per user per day**. Everything else either meters by workload, publishes no number, or is in the tens-of-requests-per-month range (Copilot Free's 50 chat requests is a hard number and it is very small).
- Cursor, Windsurf, Trae and Warp free tiers are all "real agent, unquantified or credit-starved" — they are evaluation tiers, not working tiers. Google's Antigravity free tier is the outlier that looks like a working tier, but its limit is explicitly unpublished and Google has cut it repeatedly.
- The paid-agent-software-with-free-inference column (Cline, Kilo, Aider, Continue, Crush, opencode, Goose, Qwen Code, Zed) is the only structurally free option, and it is free *conditional on* holding a free key or running local models.

## 2. Free agent vs free autocomplete — which free tiers include an actual agent?

### Takeaway
Only **GitHub Copilot Free**, **Gemini Code Assist / Gemini CLI**, and **Google Antigravity Individual** give you a free tier that includes file-editing, command-running agentic capability. Cursor Hobby, Windsurf Free, Zed Personal, Replit Free Mode, v0 Free, Lovable Free and Bolt Free are either agent-with-a-hairline-budget or, in Zed's case, explicitly *not* AI (2,000 edit predictions plus "unlimited use with your API keys or external agents").

### Cited Findings

- Copilot Free: "Agents — **Limited**"; "Free plan supports **CLI and agent mode**"; but "Copilot Chat **skills in IDEs** (Not available in Copilot Free)". — [Plans for GitHub Copilot](https://docs.github.com/en/copilot/get-started/plans-for-github-copilot), [github.com/features/copilot/plans](https://github.com/features/copilot/plans)
- Copilot Free does **not** get free third-party agents: Copilot Student explicitly "Excludes third-party agents". — [Plans for GitHub Copilot](https://docs.github.com/en/copilot/get-started/plans-for-github-copilot)
- Copilot's credit meter distinction (important for understanding what a "chat request" buys): "You use credits when you chat with Copilot, work with agents, or use Copilot CLI, Spaces, and Spark. **Code completions and next edit suggestions don't use credits.**" — [github.com/features/copilot/plans](https://github.com/features/copilot/plans)
- Copilot cloud agent is a **paid** premium-request SKU: "Copilot cloud agent uses one premium request per session, multiplied by the model's rate… each real-time steering comment made during an active session uses one premium request per session". Code review costs 13 premium requests per review as of June 1, 2026. — [Requests in GitHub Copilot (legacy)](https://docs.github.com/en/copilot/concepts/billing/copilot-requests)
- Gemini CLI is a full agent: "The Gemini CLI uses a **reason and act (ReAct) loop** with your built-in tools and local or remote MCP servers"; "Built-in tools: Google Search grounding, **file operations, shell commands, web fetching**". Apache 2.0. — [Gemini CLI docs](https://developers.google.com/gemini-code-assist/docs/gemini-cli), [google-gemini/gemini-cli](https://github.com/google-gemini/gemini-cli)
- Antigravity explicitly separates what is metered from what is not: "**Unlimited Tab completions**" and "**Unlimited Command requests**" are unmetered; the weekly cap applies to agent work. (That separation is described on Google's pricing page and analysed in secondary sources — the *mechanism* is first-party, the *interpretation* of "Command request ≠ agent run" is secondary.) — [Google Antigravity — Pricing](https://antigravity.google/pricing); [agentcode.ai — Google Antigravity](https://agentcode.ai/google-antigravity) (2026-08-16)
- Cursor Hobby: "**Limited Agent requests**; **Limited Tab completions**" — the free plan does have an agent, just capped. Frontier models and cloud agents are gated to Individual ($20). — [Cursor · Pricing](https://cursor.com/pricing)
- Windsurf Free: "Light quota to **code with agents**" — agent is present, quota is "light" and unquantified. — [Windsurf pricing](https://windsurf.com/pricing)
- Zed Personal free is deliberately **not** an AI tier: "The Personal plan is for users who want a best-in-class code editor **without AI capabilities**, or for users who prefer to use their own keys/external agents." — [Zed — Pricing](https://zed.dev/pricing)
- Amazon Q Free is an agent, but a very small one: "Included agentic requests (Q&A chat, **agentic coding**) — 50 agentic requests per month", usable "in the IDE or CLI", and Free Tier is "perpetual". — [Amazon Q Developer pricing](https://aws.amazon.com/q/developer/pricing/)
- Cline is agentic and free-to-run: "can read and write files, run terminal commands, use a browser"; "Executes in your terminal and reacts to output"; "One open source agent runtime. Use it in your editor, your terminal, or embed it in your own products. Trusted by 11M+ developers… 68.2k stars… Apache 2.0". — [Cline docs](https://docs.cline.bot/), [cline.bot](https://cline.bot/)
- Continue is agentic and free-to-run: "**Agent mode** to work on development tasks together with AI … **Autocomplete** to receive inline code suggestions as you type … **Continue CLI (cn)** for terminal-native AI coding assistance." — [Continue Docs](https://docs.continue.dev/)
- Crush, Goose, Aider, Qwen Code are all local CLI agents with no hosted free inference attached (see §4).

### Inferences
- A useful triage rule for the report: *does the free tier let the agent edit files and run commands?* Copilot Free: yes (agent mode supported, 50 requests). Gemini CLI: yes. Antigravity: yes. Cursor Hobby: yes but tiny. Amazon Q Free: yes but 50/month. Everything else: autocomplete, or free software with no free brain.

### Gaps
- Whether Copilot Free's 50 chat requests include agent-mode turns (which can be many model calls per prompt) is not stated on the first-party pages. The legacy billing doc does say "For agentic features, only the prompts you send count as premium requests; actions Copilot takes autonomously… do not" — but that doc applies to legacy annual Pro/Pro+ plans, not Free. Treat the Free-tier agent accounting as **unverified**.

## 3. BYO API key: which agents turn a free key into a free agent, and how?

### Takeaway
Every open-source / open-weight agent in the list supports BYOK, and that is the only reliable way to get an unbounded free agent today: **Cline, Kilo Code, Continue, Crush, Aider, opencode, Goose, Qwen Code, Zed (as host for external agents and via Zed Agent with your own key), Warp, Trae (paid only, not on free), Amazon Q (via Bedrock/Vertex-adjacent paths — unverified), Gemini CLI (`GEMINI_API_KEY`), and Claude Code (`ANTHROPIC_API_KEY`)**. The catch is that the *model* still costs money unless the key is one of the genuinely free allowances: Gemini API free tier, or a local model.

### Cited Findings

- **Gemini CLI** — three auth paths, all documented: "Sign in with Google" (individual accounts, no Cloud project needed), "Use Gemini API key" (`export GEMINI_API_KEY="..."` or `$env:GEMINI_API_KEY="..."` then "Select Use Gemini API key"), and Vertex AI (ADC / service-account JSON / Cloud API key with `GOOGLE_CLOUD_PROJECT`). "AI Studio user with a Gemini API key | Use Gemini API key | **Google Cloud Project Required: No**". — [Gemini CLI authentication setup](https://geminicli.com/docs/get-started/authentication/)
- **Claude Code** — "If you have an `ANTHROPIC_API_KEY`, Claude Code [uses it] for authentication instead of your Claude subscription (Pro, Max, Team, or Enterprise plans), resulting in usage charges rather than using your subscription's included usage." — [Use Claude Code with your Pro or Max plan](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)
- **Claude Code gateways** — "Setting `ANTHROPIC_AUTH_TOKEN` for a gateway you run, or signing in to a Claude apps gateway with `/login`, **turns off subscription login for that session**." Also: "The exception is setting only `ANTHROPIC_BASE_URL`, with no gateway credential. Requests still route through the gateway, but a saved claude.ai login stays the active credential, so the subscription's usage limits and billing apply." **This is a specific trap worth flagging**: setting only the base URL does *not* detach billing from your subscription. — [code.claude.com/docs/en/gateways](https://code.claude.com/docs/en/gateways)
- **Claude Code rate limiting instead of spending** — "If you're using Bedrock or Vertex, set the **Opus rate limit to 0** in your Vertex/Bedrock project settings… even if disabled in Vertex, users may be able to switch models in Claude Code, so rate limiting is the most effective approach." — [Claude Code FAQ](https://support.claude.com/en/articles/12386420-claude-code-faq)
- **Cline** — "Every model, your choice: Claude, GPT, Gemini, local Ollama / LM Studio, or any OpenAI-compatible endpoint. **Bring your own key or your own weights**." and "Cline works with every major provider. **Bring your own key, your own endpoint, or your own weights**." Also supports Antigravity, Cursor, Windsurf, JetBrains, VS Code, and a CLI. — [cline.bot](https://cline.bot/), [Cline docs](https://docs.cline.bot/)
- **Kilo Code** — "Bring your own **Anthropic, OpenAI, Google, Azure, AWS Bedrock**, or other provider keys"; "Run local models with **Ollama or LM Studio**"; "No black boxes. Inspect everything. Audit the prompt, context window, and decisions in **MIT-licensed source**. Fork, modify, self-host." Teams get "Shared BYOK"; Enterprise gets "Shared Private Gateway BYOK". — [kilo.ai](https://kilo.ai/), [Kilo Code Pricing](https://kilocode.ai/pricing)
- **Zed** — five model-access paths: "Use Zed-Hosted Models / **Use API Access** / **Use an Existing Subscription** (ChatGPT, Claude, Copilot) / **Use a Gateway** (OpenRouter, Bedrock, Vercel) / **Use a Local Model**". Plus "External Agents: ACP-integrated agents" and "Terminal Threads: terminal-backed threads for running an agent CLI or TUI directly in Zed". Free Personal plan includes "Unlimited use with your API keys or external agents like **Claude Agent, Codex CLI**, and more". — [Zed — AI overview](https://zed.dev/docs/ai/overview), [Zed — LLM Providers](https://zed.dev/docs/ai/llm-providers), [Zed — Pricing](https://zed.dev/pricing)
- **Aider** — documents connections to OpenAI, Anthropic, Gemini, GROQ, LM Studio, xAI, Azure, Cohere, DeepSeek, **Ollama** (fully local), OpenAI-compatible APIs, OpenRouter, **GitHub Copilot**, Vertex AI, Amazon Bedrock; API keys via env/`.env`/YAML config. — [aider.chat/docs](https://aider.chat/docs/) (index page listing `llms/ollama.html`, `llms/openrouter.html`, `llms/github.html`, `llms/bedrock.html`, `config/api-keys.html`, `dotenv.html`)
- **Crush** — "Multi-Model: choose from a wide range of LLMs or add your own via **OpenAI- or Anthropic-compatible APIs**"; config example shows `base_url` + `api_key` + custom `models` per provider; supports MCP (http, stdio, sse); works on macOS/Linux/Windows/Android/BSD. — [charmbracelet/crush](https://github.com/charmbracelet/crush)
- **opencode** — "you can use **any LLM provider by configuring their API keys**"; `/connect` command → opencode.ai/auth; also OpenCode Zen, and any OpenAI-compatible endpoint. — [opencode Docs — Intro](https://opencode.ai/docs/)
- **Warp** — Free includes "**Bring your own AI inference**"; Build includes "Full Warp Agent access (frontier and open-source models from **OpenAI, Anthropic, z.ai**, and more)"; Business and Enterprise explicitly support "Bring your own API keys and custom inference endpoints" and "(BYOLLM)". — [Warp — Pricing](https://warp.dev/pricing)
- **opencode Zen** as a shared gateway usable outside opencode: "Use Zen with any agent. Set monthly spend limits."; "All Zen models are hosted in the US. Providers follow a **zero-retention policy** and do not use your data for model training, with the following exceptions." — [OpenCode Zen](https://opencode.ai/zen)
- **Kilo Gateway** as a shared inference router: "Pay-as-you-go hosted AI inference with no subscription… **500+ models across 60+ providers**… Pay exact provider rates **with no markup**". — [Kilo Code Pricing](https://kilocode.ai/pricing)
- **The genuinely free model key to point all of this at**: Gemini Developer API free tier — "Free input & output tokens", "Free of charge" for input/output/context-caching on `gemini-3.8-flash` and `gemini-3.7-flash`, with "Google AI Studio access". The trap: the free tier's "**Used to improve our products: Yes**" while paid is "No" — i.e. free-tier traffic is explicitly used for product improvement. — [Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing)

### Inferences
- The practical "free agent" stack today is: an open-source harness (Cline / Kilo / opencode / Crush / Aider / Goose / Continue) pointed at the **Gemini Developer API free tier** or a **local model via Ollama/LM Studio**. That combination is genuinely unbounded-by-subscription and the harness costs $0.
- Two named BYOK traps: (1) Claude Code with only `ANTHROPIC_BASE_URL` set still bills your subscription; (2) the Gemini API free tier explicitly trains on your data, unlike paid tier. Anyone whose threat model cares should know both.
- Zed's free tier is the cleanest "free editor + whatever agent you like" story, because it explicitly licenses "unlimited use with your API keys or external agents like Claude Agent, Codex CLI".

### Gaps
- **Qwen Code** could not be fetched (`qwenlm.github.io/qwen-code-docs/` rendered as an empty "Qwen Studio" shell; `docs.qwen.ai/qwen-code-docs/en/` errored). Its BYOK/free-tier status is **unverified**. Same for **Goose** (Block) — I read the install page but not a models/providers page, so its BYOK provider list and whether Block funds any free inference is **unverified**.
- **Continue's** provider list page (`docs.continue.dev/customize/model-providers/top-anthropic`, `docs.continue.dev/governance/ai-pricing`) failed to fetch. Continue is known to be BYOK but I could not cite a first-party page this session. Mark as **unverified pending a docs fetch**.
- **Kilo Code's "Auto Free" routing** — "Auto Free routes to free models through Kilo Gateway where available" — does not name which free models. **Unverified.**
- Whether **Amazon Q** can be pointed at a Bedrock/Vertex key is **unverified** — the pricing page only shows IAM/Builder ID auth.
- Whether **Cline** or **Kilo** offer any first-party free *inference* credit (as opposed to BYOK/local) is **unverified**; Cline's marketing line is "Every model, your choice … Bring your own key".

## 4. Real-world rate limits users actually hit (hard cap vs soft budget vs observation)

### Takeaway
Three genuinely *hard, published* caps stand out — Gemini Code Assist **1,500 requests/user/day**, Amazon Q Free **50 agentic requests/month**, Copilot Free **50 chat requests/month** (plus 2,000 completions). Everything else in the hosted category is a *soft* budget (credits you can top up) or an *unpublished* workload meter, and the most user-visible failure mode across the whole category in 2026 is **Antigravity's weekly quota**, which users report failing to reset and being silently cut.

### Cited Findings — hard limits (stated caps)

- Gemini Code Assist agent mode + Gemini CLI: "**Maximum requests per user per day: Standard 1500, Enterprise 2000**"; "**Requests per second: 2**"; "These daily request limits are **aggregated across all interactions with any model version or family** (for example, Pro, Flash)… Once the maximum number of requests per day is reached, no further requests can be made through these interfaces to any model until the quota resets." ### Inferences
- The distinction the brief asks for matters concretely here. Gemini Code Assist's 1,500/day is a **hard cap you cannot buy your way past** on the free tier ("no further requests can be made through these interfaces to any model until the quota resets"). Copilot's is a **soft budget** — you can set a dollar budget and keep going (subject to a discretionary additional-usage cap). Antigravity's free weekly quota is **unpublished and capacity-dependent**, which is a fourth category: not hard, not soft, but *variable*, and the variable axis is Google's compute at that moment.
- The failure modes users report are not "the model got worse" — they are "the meter fired early and did not reset", plus "the number shrank without notice". Anyone standardising a team on a free tier should treat reset reliability as a first-class risk.
- Gemini Code Assist is the only free tier where the accounting is *predictable* (daily, aggregated across models, clearly stated), which is why it is the practical recommendation for sustained free agentic work.

### Gaps
- No first-party page publishes the Antigravity free weekly quota, and no first-party page explains the Flash/Pro pool merge in enough detail to quantify it.
- Whether the Gemini CLI free/individual route genuinely closed on 2026-06-18 is **unresolved**: one secondary source says it did, first-party auth docs read as if it did not.
- Copilot Free's actual credit allowance (in credits) is not published, so the practical monthly agent budget on Copilot Free cannot be computed. **Unverified.**

## 5. Commercial-use restrictions, training-data terms, and licence acceptance on free tiers

### Takeaway
The training-data question is the sharpest one. The Gemini **API** free tier explicitly uses your data to improve Google's products, while the paid tier does not; Amazon Q Free is **opt-out** for data collection while Pro is automatically opted out; Cursor's free Hobby tier has **no privacy mode** (that's a Teams/paid feature per the docs table); and Windsurf/Copilot free terms allow training. Several free tiers are explicitly restricted to personal, non-commercial use.

### Cited Findings

- **Gemini Developer API free tier trains on your data**: the pricing page's per-model rows end with "**Used to improve our products: Yes**" for the Free tier and "**No**" for Paid and Enterprise. The Free tier is described as "For developers and small projects getting started" and lists "**Content used to improve our products***". — [Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing)
- **Gemini Code Assist has a data-protection boundary**: "For users of Gemini Code Assist **Standard and Enterprise**, the data protection and privacy practices described in *Security, privacy, and compliance for Gemini Code Assist Standard and Enterprise* also apply to Gemini CLI." — [Gemini CLI | Gemini for Google Cloud](https://developers.google.com/gemini-code-assist/docs/gemini-cli). **The Standard-edition privacy terms themselves are in a separate page I did not fetch — the commercial-use question for the free Gemini Code Assist tier is therefore only partially answered. Unverified.**
- **Amazon Q data collection**: Free tier "Data collection — **Opt-out available**"; Pro tier "Data collection — **Automatically opted out**". Also "**IP indemnity: Free — No; Pro — Yes**", and "Suppress public code suggestions — Yes" on both. — [Amazon Q Developer pricing](https://aws.amazon.com/q/developer/pricing/)
- **Amazon Q free tier identity requirement / commercial shape**: "Amazon Q Developer offers a perpetual Free Tier with monthly limits available to users logged in as an **AWS IAM user or AWS Builder ID user**." and "**Free Tier limits in the IDE are available only to Builder ID users.**" Free-tier limits apply "at the account level when logged in as an IAM user, or at the user level for AWS Builder ID users" — i.e. the free allowance is account-scoped for IAM, which matters for commercial teams sharing an account. — same page
- **Cursor privacy mode is not on the free plan**: "**Privacy mode** can be enabled in settings or by a team admin. When it is enabled, we guarantee that code data is not used for training by us or our model providers." In the plan comparison table, "Team-wide privacy mode" is listed only under **Teams ($40/user/mo)**; Personal privacy mode is not listed as a plan-tier feature. **The consequence for Hobby users is an inference, not a quote — mark as unverified-but-likely: Hobby data is used for training.**
- **OpenCode Zen privacy posture**: "All Zen models are hosted in the US. Providers follow a **zero-retention policy** and do not use your data for model training, with the following exceptions." — [OpenCode Zen](https://opencode.ai/zen)
- **Sourcegraph Cody**: "Sourcegraph **does not use any of your data to train models**" for individuals on Sourcegraph.com (but "Sourcegraph may use your prompts and responses to enhance the user experience"). Also, per the same page, "Cody is supported on Sourcegraph Enterprise" — the page is enterprise-scoped. — [Sourcegraph Cody](https://sourcegraph.com/cody)
- **v0 training opt-out is a paid feature**: Free has no training opt-out; **Business** includes "**Training opt-out by default**" and Enterprise "Your data is never used for training". — [v0 by Vercel](https://v0.dev/pricing)
- **Replit**: "Replit Agent is powered by large language models. While it can produce powerful results, its behavior is probabilistic - meaning it may occasionally make mistakes." No training terms stated on the pricing page. — [Replit pricing](https://replit.com/pricing)
- **Lovable / Bolt**: no data-training or commercial-use terms on the pricing pages I read. **Unverified.**
- **Cline**: "Open source. Plan-and-Act. Every model. **No vendor lock-in**"; Apache 2.0 — you run it locally against your own key, so the data question moves to whichever provider you chose. — [cline.bot](https://cline.bot/)
- **Kilo Code**: "No black boxes. **Inspect everything.** Audit the prompt, context window, and decisions in MIT-licensed source. Fork, modify, self-host." Teams adds "Data privacy controls". — [kilo.ai](https://kilo.ai/)
- **Windsurf/Devin free tier commercial terms**: not stated on the pricing page. Note the trial-eligibility rule instead: "Trials are generally not offered to: Customers who have previously used Windsurf, Devin, or Codeium… Customers flagged for suspected abuse, fraud, or other violations of our terms of service. **Eligibility is determined automatically by our systems and is not subject to appeal.**" — [Windsurf Plans and Usage](https://docs.windsurf.com/windsurf/accounts/usage)
- **Tabnine**: "**Zero code retention and total privacy** – No storage, no training on your code, no sharing with third parties" and "**License-safe AI usage**. Built-in protection against licensing risks" (IP indemnification "subject to terms and conditions") — but this is the $39–59/user/month enterprise product. — [Tabnine Plans & Pricing](https://www.tabnine.com/pricing)
- **JetBrains**: Junie free trial terms **unverified**; the Junie page carries no commercial-use or data-training statement I read.
- **Antigravity licensing**: "Antigravity IDE is not supported for enterprise customers" and the Enterprise route is "Access under **Google Cloud Terms of Service**" — i.e. using the free Individual tier for commercial work may sit outside the intended licence. **Worth flagging as a legal-risk item; the exact free-tier commercial terms are unverified.**

### Inferences
- For a commercial team wanting a free agent, the cleanest option is a **local harness + your own key + a provider tier that doesn't train** (paid Gemini, OpenRouter, Bedrock, or a local model). Every "free tier" that trains on your data is disqualified for commercial/proprietary code, and that includes the Gemini Developer API free tier — which is exactly the key people reach for when trying to make a paid agent free.
- The most consequential licence/trap finding is Antigravity: the free Individual tier is the most capable free agent, and simultaneously the one Google says is not supported for enterprise customers. That is a real "don't standardise your company on this" signal, and it is first-party-quoted from a Google forum answer.

### Gaps
- **Commercial-use permission on free tiers is, for most tools, not addressed on the pricing or docs pages I read.** Specifically unverified: Gemini Code Assist Standard edition's commercial-use terms (separate privacy page not fetched), Windsurf Free, Cursor Hobby, Trae Free, Warp Free, Replit Free, JetBrains AI, and v0 Free.
- **Phone-number / credit-card requirements** were not addressed by any page I read except Cursor ("**No credit card required**" on Hobby). Whether Gemini CLI / Copilot Free / Antigravity require a phone number for signup is **unverified** — the docs do not state it either way.

### Takeaway
The dominant movement is **conversion of previously-unlimited free tiers into credit-metered ones, and conversion of Google-stack free access into an Antigravity-shaped subscription**. Three specific 2026 events dominate: Roo Code's shutdown (May 15), GitHub's move to AI Credits for all plans (June 1), and Antigravity's free-tier quota cuts. Gemini CLI's free route may also have closed on June 18 — contested.

- **Roo Code shut down 2026-05-15**: "The Roo Code Extension was shut down on **May 15th**." Successor pointers: "**ZooCode** (a fork started by the Roo Code community) and **Cline** (from where Roo Code originated)." — [Roo Code Docs](https://docs.roocode.com/)

### Inferences
- The 12-month story is one of **withdrawal of free inference, not withdrawal of free software**. Vendor-hosted free tiers got smaller and switched to opaque meters; open-source agents got *better* (more model paths, local-model support, MIT/Apache licences) and are now the only durable free-agent route.
- A second thread: **BYOK went mainstream in the other direction too** — GitHub's own docs now meter "third-party coding agents" as billable Copilot SKUs, i.e. the incumbent subscription vendor is starting to charge for the thing the free OSS agents give away. Expect that to tighten.
- Three acquisitions in the free-agent space (Anaconda/Kilo, Tricentis/Tabnine, Cognition/Windsurf-into-Devin) suggest consolidation around paid enterprise rather than continued free-tier investment.
