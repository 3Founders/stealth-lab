## problem
Onboarding a non-CS "vibe coder" to a codebase means reading it cold; there's no guided, visual explanation.

## goal
Produce one offline HTML file that teaches the codebase: code↔plain-English, animated data-flow, quizzes, glossary.

## preconditions
- Claude Code environment; target codebase in the project; skill installed under `~/.claude/skills/`.

## steps
1. Place the `codebase-to-course` skill folder in `~/.claude/skills/`.
2. Open the target project in Claude Code.
3. Invoke with a trigger phrase (e.g. "Turn this into a course").
4. The skill extracts file architecture + dependency map; generates side-by-side code↔plain-English; animated data-flow visualizations; scenario quizzes; glossary tooltips.
5. Emit one standalone offline HTML file.

## decision points
- Large codebase → focus the course on the core module/dependency spine, not every file.

## postconditions
- A single dependency-free HTML file with scroll modules, code translations, animations, working quizzes, glossary.

## verification
- HTML opens offline; shows code↔plain-English, scroll-based modules, and functioning quiz elements.

## failure/recovery
- Course is shallow → the architecture extraction missed the real entry points; point it at them explicitly.

## implementation
Claude Code skill + `references/` design system + interactive-element patterns. Deterministic HTML generation.
