# S48 — Publish a reusable module to the Terraform Registry

- **Source:** registry.terraform.io — docs at `developer.hashicorp.com/terraform/registry/modules/publish`
- **License:** HashiCorp docs (site terms); published modules are third-party licensed — review per module.
- **Locator:** §§"Requirements" / "Publishing a Public Module" / "Releasing New Versions"

## problem
Infrastructure patterns get copy-pasted between repos; there's no versioned, discoverable, documented shared module.

## goal
Publish a module so `terraform` users can `source = "<namespace>/<name>/<provider>"` it with pinned versions.

## preconditions
- A public GitHub repo named `terraform-<PROVIDER>-<NAME>` (e.g. `terraform-aws-ec2-instance`); the standard module structure; a GitHub description set.

## steps
1. Ensure the repo meets the requirements: naming, standard module structure, at least one release tag with semantic versioning (`v1.0.4` or `0.9.2`).
2. Go to the Terraform Registry → "Upload".
3. Connect with GitHub if not signed in.
4. Select the repo (the list is filtered to the naming convention) → "Publish Module".
5. The module is created "in a few seconds".
6. To release a new version: create and push a new semver tag; the webhook syncs it "usually in less than a minute". Use "Resync Module" if it lags.

## decision points
- Breaking change → bump the major version; consumers pin with `version = "~> X.Y"`.
- Private/internal module → use a private registry, not the public one.

## postconditions
- Module listed on the registry with docs auto-generated from the repo; new tags appear as versions.

## verification
- The module page loads; a `module` block with `source` + `version` resolves and `terraform init` downloads it.

## failure/recovery
- New tag doesn't appear → "Resync Module"; check the webhook delivered.

## implementation
GitHub repo + semver tags + the registry's GitHub webhook. Deterministic once the repo conforms.

## source evidence
> "The upload page will list your available repositories, filtered to those that match the naming convention"; "At least one release tag must be present" using semantic versioning; "The webhook will notify the registry of the new version and it will appear on the registry usually in less than a minute."
