# S38 — Represent a replayable, gradable SE agent trajectory

- **Source:** huggingface.co/datasets/nebius/SWE-rebench-openhands-trajectories · card rev ~2025-12-23 · CC-BY-4.0
- **Locator:** dataset card; per-record fields. 67,074 rows / 1,823 repos / 2.08 GB. **Do not download the parquet — the card is the artifact.**

## problem
An agent run needs to be stored so that (a) it can be replayed/inspected step by step and (b) its success can be judged without a human.

## goal
Define the record shape that makes an SE agent run both replayable and automatically gradable.

## preconditions
- A completed agent run over a GitHub-issue task (here: OpenHands v0.54.0 + Qwen3-Coder-480B).

## steps
1. Capture `trajectory` — the complete role-tagged conversation history (`system` / `assistant` / `user` / `tool`).
2. Capture `model_patch` — the final code modifications as a unified diff.
3. Capture `exit_status` — termination indicator or error message.
4. Capture `resolved` — binary success indicator.
5. Capture generated-test signals — `gen_tests_correct` (are the generated tests valid) and `pred_passes_gen_test` (does the patch pass them).
6. Key each record by `trajectory_id` + `instance_id` (the GitHub-issue reference).

## decision points
- Grade by the task's own `FAIL_TO_PASS` (S36) when available; use generated-test signals as a secondary check.

## postconditions
- A record from which the run can be re-read turn by turn and scored resolved/not.

## verification
- Replaying `trajectory` reproduces the decisions; `resolved` matches re-running the tests on `model_patch`.

## failure/recovery
- `resolved` disagrees with a re-run → environment drift; pin and re-score.

## implementation
Dataset schema (Parquet on HF); consumed by training / analysis pipelines. Not executable itself.

## source evidence
> fields verbatim: `trajectory` ("Complete conversation history with roles: 'system', 'assistant', 'user' and 'tool'"), `model_patch` ("Final code modifications … in unified diff format"), `exit_status`, `resolved`, `gen_tests_correct`, `pred_passes_gen_test`.
