# S10 — Fresh-context autonomous loop ("Ralph")

- **Source:** ghuntley.com/ralph/ · published 2025-07-14 · Geoffrey Huntley
- **License:** NONE stated — standard blog copyright. **Study/reference only; not redistributable.**

## problem
A long agent session accumulates a huge transcript; the model degrades, drifts, and loses the plot over hours of work.

## goal
Run a coding agent for hours without carrying the whole transcript, by rebuilding a small focused context every iteration.

## preconditions
- A written spec; `AGENT.md` documenting the build process; a `fix_plan.md` of prioritized work; a stdlib/scaffold established.

## steps
1. Start each iteration from a fresh context: re-load the spec + `fix_plan.md` only.
2. Have the agent pick the single highest-priority item and do just that (parallel subagents allowed).
3. Execute the generated code; capture results.
4. Run tests / static analysis as backpressure.
5. Update `fix_plan.md` with findings and what's left.
6. Commit; create a git tag.
7. Loop: `while :; do cat PROMPT.md | claude-code ; done`.

## decision points
- Item too big for one iteration → split it in `fix_plan.md` first.
- Tests fail → the next iteration's top priority becomes the failure.

## postconditions
- Code compiles; tests pass; git history + tags advance; `fix_plan.md` reflects remaining work.

## verification
- Stopping condition: no high-priority items left in `fix_plan.md`, or codebase stability reached.

## failure/recovery
- Loop thrashes on the same item → the item is under-specified; rewrite its `fix_plan.md` entry.

## implementation
A shell `while` loop around a coding-agent CLI; state lives in `fix_plan.md` + git, not in context. Provider: any agent CLI.
