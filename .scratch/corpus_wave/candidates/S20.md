# S20 — Context Rot: claims + evidence on long-context degradation

- **Source:** trychroma.com/research/context-rot · 2025-07-14 · Hong, Troynikov, Huber (Chroma)
- **License:** cite-as-techreport (BibTeX provided); no explicit reuse license — **citation/reference only**
- This is primarily a **claim/evidence** source, not a procedure. The reproducible method is S19.

## problem (what the report addresses)
Whether LLMs use long context uniformly, and what makes long-context tasks fail.

## method (as reported)
18 models (Claude 4 / GPT-4.1 / Gemini 2.5 / Qwen3 families); 8 input lengths; tasks: NIAH-extension (needle-in-haystack with controlled needle-question similarity, distractors, haystack structure), LongMemEval (focused ~300 tok vs full ~113k tok), Repeated Words (output-fidelity as context grows, 25–10,000 words). Scoring: LLM judge (GPT-4.1) aligned to >99% human agreement over ~500–600 manual labels per benchmark; normalized Levenshtein for strings; cosine similarity across 5 embedding models.

## verification
Independent replication supported: full codebase (S19) + cleaned datasets + prompts published.

## implementation
n/a — analysis report. The executable form is S19.

## source evidence (verbatim)
> "Models do not use their context uniformly; instead, their performance grows increasingly unreliable as input length grows."
> "As needle-question similarity decreases, model performance degrades more significantly with increasing input length."
> "Even a single distractor reduces performance relative to the baseline (needle only), and adding four distractors compounds this degradation further."
> "Models perform better on shuffled haystacks than on logically structured ones."
> "Across all models, we see significantly higher performance on focused prompts compared to full prompts." (LongMemEval: ~300 tok vs ~113k tok)
