# S03 — Deploy a project to Vercel as a claimable deployment

- **Source:** github.com/vercel-labs/agent-skills @ `main@063bee9` · MIT
- **Locator:** `README.md` §"vercel-deploy-claimable" (skill dir `skills/vercel-deploy-claimable/`)

## problem
An agent has built a web project and needs to get it live and hand ownership to a human, without the human doing the deploy dance.

## goal
Produce a live preview URL plus a claim URL that transfers the deployment to a Vercel account.

## preconditions
- Project dir has `package.json` (or is static HTML); `node`/`npx` available.
- Skill pack installed: `npx skills add vercel-labs/agent-skills`.

## steps
1. Invoke the `vercel-deploy-claimable` skill.
2. Package the project into a tarball (exclude `node_modules`, `.git`, build artifacts).
3. Detect the framework (Next.js, Vite, Astro, …; 40+ supported).
4. Upload to the deployment service.
5. Return the preview URL and the claim URL.

## decision points
- Static HTML vs framework project → different build handling.
- If framework detection is wrong, override explicitly.

## postconditions
- Preview URL reachable; claim URL valid for ownership transfer.

## verification
- Output contains `Preview URL: https://…` and `Claim URL: https://vercel.com/claim-deployment?code=…`.
- Preview URL renders the app.

## failure/recovery
- Build fails → inspect framework detection + tarball contents; retry with explicit framework.
- Claim URL expired → redeploy.

## implementation
CLI skill wrapping a deployment API; deterministic packaging + a hosted build. Provider: Vercel deploy service.
