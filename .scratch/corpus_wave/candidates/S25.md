# S25 — Set up an agent harness (global rules + project context + skills + delegation)

- **Source:** github.com/charlie947/agent-harness-starter @ `main@HEAD` (SHA not pinned) · MIT
- **Locator:** `templates/CLAUDE.md` §"What you get"; `/agent-harness-setup` skill

## problem
A fresh agent environment has no global rules, no place for project context, no delegation routing, and no memory of past corrections.

## goal
Establish a structured harness: global personalisation, project-specific rules, memory indexing, delegation routing, and skill orchestration.

## preconditions
- Claude Code installed; bash access; git available.

## steps
1. `git clone https://github.com/charlie947/agent-harness-starter ~/agent-harness-starter`.
2. `bash ~/agent-harness-starter/install.sh`.
3. Restart Claude Code.
4. Invoke `/agent-harness-setup`.
5. Complete the interactive walkthrough for global + project configuration.

## decision points
- Global vs project rule → personal preferences global; repo conventions project-scoped.
- Repeated correction → route it into the memory index so it sticks across sessions.

## postconditions
- `~/.claude/` populated with templates; the slash command registered; delegation + skill orchestration wired.

## verification
- `/agent-harness-setup` runs; templates land in the designated directories.

## failure/recovery
- Slash command missing after install → the restart was skipped; restart and retry.

## implementation
Shell installer + templates + a setup skill; deterministic scaffold. Provider: Claude Code / Cowork.
