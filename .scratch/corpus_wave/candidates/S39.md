# S39 — Hybrid-reasoning multilingual trajectory synthesis (Open-SWE-Traces)

- **Source:** huggingface.co/papers/2606.16038 — "Open-SWE-Traces: Advancing Dual-Mode Multilingual Distillation for Software Engineering Agents"
- **License:** paper under arXiv terms; dataset `nvidia/Open-SWE-Traces` — check its card before ingest.
- **Locator:** paper abstract + method section.

## problem
Training data for SE agents is scarce and skewed toward a few languages and a single reasoning style.

## goal
Synthesize a large, diverse trajectory dataset that covers many languages and both explicit-reasoning and terse styles.

## preconditions
- A pool of real repo-level SE tasks across multiple languages; two generator models of different character.

## steps
1. For each task, run **hybrid-reasoning synthesis**: Minimax-M2.5 generates a trajectory *with* an explicit "thinking" process.
2. In parallel, Qwen3.5-122B generates a high-quality *"non-thinking"* trace for the same task.
3. Collect both modes across nine programming languages → 207,489 trajectories.
4. Fine-tune models on the mixed-mode data.
5. Validate by benchmarking the fine-tuned models on multiple SE benchmarks.

## decision points
- Keep thinking + non-thinking as separate splits so downstream training can weight them.

## postconditions
- A dual-mode, 9-language trajectory corpus; fine-tuned models with reported benchmark gains.

## verification
- Fine-tuned models show "strong performance on multiple benchmarks" (paper's own validation).

## failure/recovery
- One generator dominates quality → rebalance the mode mix rather than dropping a mode.

## implementation
LLM-driven data synthesis pipeline (two generators, mode-tagged); output is a training dataset. Not executable.
