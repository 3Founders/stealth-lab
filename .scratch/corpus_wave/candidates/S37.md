# S37 — Run an SE agent task in an executable RL environment (SWE-Gym)

- **Source:** github.com/SWE-Gym/SWE-Gym @ `main@HEAD` (SHA not pinned)
- **License:** UNVERIFIED — confirm LICENSE before ingest (paper arXiv:2412.21139)
- **Locator:** `README.md`; the SWE-Gym environment (2.4K real Python tasks / 11 repos; Lite = 234)

## problem
Agents for software engineering lack training environments that combine real repo-level tasks, executable context, and rigorous verification for RL.

## goal
Execute an agent against a real repo-level task in an environment that returns a verifiable binary reward, producing trajectories usable for training agents/verifiers.

## preconditions
- SWE-Gym installed; a task instance with its executable environment + tests.

## steps
1. Load a task: a real Python repo-level issue with repository context, an executable environment, and test verification.
2. Run the agent; it explores the repo and produces a patch.
3. Execute the task's tests against the patched repo.
4. Derive a binary reward from the verification (resolved / not).
5. Keep the full trajectory (steps + outcome) for training a policy or a verifier.

## decision points
- Full 2.4K set vs the 234-instance Lite split → Lite for fast iteration, full for final numbers.
- Training a verifier vs an agent → same trajectories, different target.

## postconditions
- A scored trajectory (reward + full step log) per run.

## verification
- Reward is test-derived (same flip-the-tests logic as S36), not model-judged.

## failure/recovery
- Environment flaky → pin it; a flaky env corrupts the reward signal.

## implementation
SWE-Gym harness (executable envs + test verification); trajectories feed RL / rejection sampling. Provider: SWE-Gym.

## source evidence
