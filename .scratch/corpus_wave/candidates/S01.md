# S01 — Author a new Agent Skill

- **Source:** github.com/anthropics/skills @ `main@53048666` · Apache-2.0 (doc skills source-available)
- **Locator:** `README.md` §"Creating a Basic Skill" + `template/SKILL.md`

## problem
An agent repeatedly needs the same specialised instructions for a class of task, but re-typing them each prompt is lossy and inconsistent.

## goal
Produce a valid, loadable Agent Skill: a folder with a `SKILL.md` that a model can discover and follow.

## preconditions
- The skill's purpose and its triggering conditions are known.
- Markdown authoring available; optional `template/` to copy.

## steps
1. Create a folder named for the skill (lowercase-hyphenated).
2. Add `SKILL.md` inside it.
3. Add YAML frontmatter with required `name` and `description` (what it does **and when to use it**).
4. Write the markdown body: the instructions the model will follow.
5. Add an "Examples" section (concrete example invocations).
6. Add a "Guidelines" section (best practices / limits).
7. Start from `template/SKILL.md` rather than a blank file.

## decision points
- Bundle helper scripts/resources under the folder only if they are reused; otherwise inline.
- If triggering is ambiguous, make the `description` "pushier" about when to fire.

## postconditions
- Folder contains a well-formed `SKILL.md` (frontmatter + body).
- Skill is registrable / uploadable.

## verification
- `name` is lowercase with hyphens; `description` states capability + when-to-use.
- Body renders as valid markdown; structure matches `template/SKILL.md`.

## failure/recovery
- Model never invokes the skill → tighten `description` triggers, add should-trigger examples.
- Body too long / unfocused → split or trim to the single task.

## implementation
Deterministic authoring; no runtime. Output is a text artifact consumed by a skill-aware agent runtime.
