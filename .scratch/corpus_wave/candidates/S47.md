# S47 — Debug a running / crashing Kubernetes pod

- **Source:** github.com/kubernetes/website `/content/en/docs/tasks/debug/debug-application/debug-running-pod.md` @ `main@HEAD` (SHA not pinned) · CC-BY-4.0 (attribute "The Kubernetes Authors")
- **Locator:** slug `/docs/tasks/debug/debug-running-pods`

## problem
A pod is crashing or misbehaving and you need to diagnose it without disturbing the workload more than necessary.

## goal
Identify the cause of a running/crashing pod's problem using progressively more invasive tools, then clean up.

## preconditions
- `kubectl` access to the cluster; the pod is scheduled (running or crash-looping).

## steps
1. `kubectl describe pod ${POD_NAME}` — container state, readiness, restart count, events.
2. `kubectl logs ${POD_NAME} -c ${CONTAINER_NAME}` and `--previous` for the last crashed instance.
3. `kubectl exec -it ${POD_NAME} -- sh` (or `-c ${CONTAINER_NAME} -- ${CMD}`) to inspect from inside.
4. If the container has no shell/tools: `kubectl debug -it ${POD_NAME} --image=busybox:1.28 --target=${CONTAINER_NAME}` (ephemeral debug container).
5. To change the spec safely: `kubectl debug ${POD_NAME} --copy-to=${POD_NAME}-debug --image=ubuntu`.
6. For node/network issues: `kubectl debug node/${NODE_NAME} -it --image=ubuntu`.
7. Clean up debug pods when finished.

## decision points
- Distroless / no shell → ephemeral debug container (step 4), don't rebuild the image.
- Need to alter command/env to reproduce → pod copy (step 5), never edit the live pod.

## postconditions
- Root cause identified from events/logs/inside-container inspection; debug artifacts removed.

## verification
- `kubectl describe pod` / `kubectl get events` confirm the diagnosed state; debug pods are deleted.

## failure/recovery
- Ephemeral container can't attach → the feature gate / cluster version doesn't support it; fall back to a pod copy.

## implementation
`kubectl` CLI; deterministic. Provider: any Kubernetes cluster.

## source evidence
> commands verbatim: `kubectl describe pod ${POD_NAME}`; `kubectl logs ${POD_NAME} -c ${CONTAINER_NAME} --previous`; `kubectl debug -it ${POD_NAME} --image=busybox:1.28 --target=${POD_NAME}`; `kubectl debug ${POD_NAME} --copy-to=${POD_NAME}-debug --image=ubuntu`.
