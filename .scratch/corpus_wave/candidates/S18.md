# S18 — Discover and use an agent skill from any git source

- **Source:** github.com/vercel-labs/skills @ `main@435076e7` · **license UNVERIFIED — confirm before ingest**
- **Locator:** `README.md` §§"Install a Skill" / "Use a Skill Without Installing" / "Source Formats"

## problem
Skills live in many repos in many host formats; an agent needs one resolver to fetch and apply the right one without a bespoke integration per source.

## goal
Install or one-shot-use a named skill from a GitHub/GitLab/SSH/local source with a single command.

## preconditions
- `npx` available; git credentials configured for private sources (credential helper / `gh` / SSH).

## steps
1. Install: `npx skills add vercel-labs/agent-skills` (or a full URL / `tree/` path / GitLab URL / `git@…` / local path).
2. Or use without installing: `npx skills use vercel-labs/agent-skills@web-design-guidelines | claude`.
3. Or start an agent directly: `npx skills use <src> --skill <name> --agent claude-code`.
4. For private repos, use the same command — the CLI reuses existing git auth (credential helper → `gh repo clone` → SSH).

## decision points
- Need the skill persistently → `add`; one-off → `use`.
- Private source → rely on already-configured git auth; the CLI never runs `gh auth token`.

## postconditions
- Skill files present in the project (`add`) or written to a temp dir and a prompt/agent session started (`use`).

## verification
- The target agent loads the skill; `skills` resolved the source format correctly.

## failure/recovery
- Auth fails → the CLI falls back credential-helper → `gh` → SSH; fix whichever layer is missing.

## implementation
Node CLI; git clone + file copy + prompt generation; supports 77+ agent formats. Deterministic resolver.
