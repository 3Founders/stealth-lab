# S43 — Verify a scientific claim against evidence (SciFact protocol)

- **Source:** github.com/allenai/scifact @ `master@HEAD` (SHA not pinned)
- **License:** code Apache-2.0; **SciFact data CC BY-NC 2.0 (NON-COMMERCIAL)** — verify before any shared/commercial use.
- **Locator:** `doc/{data.md,evaluation.md,model.md}`; `claims_*.jsonl` + `corpus.jsonl`

## problem
Given a claim, decide whether the literature supports it, contradicts it, or says nothing — and show the sentences that justify the call.

## goal
Produce a label (SUPPORT / CONTRADICT / NOINFO) for a claim plus the rationale sentences from the cited abstracts.

## preconditions
- The claim text; a corpus of evidence abstracts (`corpus.jsonl`, one document per line); claims file (`claims_*.jsonl`, one claim per line).

## steps
1. Retrieve candidate documents for the claim — oracle (gold cited docs) or open retrieval.
2. Select rationale sentences within each candidate — threshold- or model-based sentence selection.
3. Predict the label from the claim + selected rationales: SUPPORT / CONTRADICT / NOINFO.
4. Evaluate with the repo's scripts against the dev set — sentence-selection F1 + label accuracy.

## decision points
- No rationale clears the selection threshold → NOINFO, not a guessed label.
- Multiple documents disagree → report per-document labels; the claim-level label is the aggregate rule in `doc/evaluation.md`.

## postconditions
- `{claim_id, predicted_label, evidence: {doc_id: [sentence_ids]}}` per claim.

## verification
- Run the repo's evaluation script; compare sentence-selection + label metrics to the paper's numbers.

## failure/recovery
- Label accuracy collapses → the rationale selector is over/under-selecting; tune the threshold before touching the classifier.

## implementation
`verisci/` Python pipeline (retrieval → rationale selection → label); deterministic eval scripts. Provider: SciFact repo.

## source evidence
> `doc/data.md` (schemas), `doc/evaluation.md`; three-way label SUPPORT/CONTRADICT/NOINFO; "Run models for paper metrics" via shell scripts. Cite Wadden et al., EMNLP 2020.
