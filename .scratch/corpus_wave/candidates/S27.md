# S27 — Generate a shareable single-file HTML slide deck

- **Source:** github.com/zarazhangrui/frontend-slides @ `main@9906a34d` · MIT
- **Locator:** `SKILL.md` + `STYLE_PRESETS.md` + `html-template.md` + `scripts/`
- **Wave role:** flagship visual proving case (§28).

## problem
Non-designers need a presentation and end up hand-building brittle HTML or fighting slide software.

## goal
Produce one self-contained HTML file (inline CSS/JS, zero dependencies) that renders a full deck and is shareable by URL or PDF.

## preconditions
- Claude Code with filesystem/shell access; the frontend-slides skill installed; a content outline (titles, images, optional `.pptx`).

## steps
1. Invoke `/frontend-slides:frontend-slides`.
2. Provide content — describe the slides, or upload a `.pptx` (`scripts/extract-pptx.py` extracts it).
3. Review 3 generated style preview cards; pick an aesthetic.
4. The skill renders the full presentation in the chosen style and opens it in the browser.
5. (optional) `scripts/deploy.sh` (Vercel) or `scripts/export-pdf.sh`.

## decision points
- `.pptx` supplied → extract-first; freeform description → generate structure from the outline.
- None of the 3 previews fit → ask for another set rather than forcing one.

## postconditions
- One `.html` file, inline CSS/JS, no external deps; navigable by keyboard/click.

## verification
- Open the `.html`; slides advance; text, images, animations render; (if deployed) the URL loads.

## failure/recovery
- Layout breaks on a slide → the content overflowed the fixed stage; trim or split that slide.

## implementation
Claude Code skill: templates (`viewport-base.css`, `html-template.md`) + `scripts/extract-pptx.py` + deploy/export scripts. Deterministic render from a chosen preset.
