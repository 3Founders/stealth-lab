# S19 — Reproduce the Context Rot benchmark

- **Source:** github.com/chroma-core/context-rot @ `master@af80a080` · MIT
- **Locator:** `README.md` §"Experiments" + `experiments/{niah_extension,longmemeval,repeated_words}/README.md`

## problem
Claims about long-context degradation are easy to assert and hard to check; you need a runnable rig.

## goal
Reproduce the measured degradation curves across the three tasks and compare to the published figures.

## preconditions
- Python venv; provider API keys (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GOOGLE_APPLICATION_CREDENTIALS`, `GOOGLE_MODEL_PATH`); dataset download access.

## steps
1. `git clone https://github.com/chroma-core/context-rot`.
2. `python -m venv venv` and activate it.
3. `pip install -r requirements.txt`.
4. Set the provider API keys.
5. Download the datasets from the linked Google Drive into `data/`.
6. `cd` into an experiment folder (`experiments/niah_extension` | `longmemeval` | `repeated_words`) and follow its README.
7. Run the experiment; outputs land in `results/`.
8. Compare the produced curves against the published figures.

## decision points
- Pick one task first (repeated_words is the cheapest signal) before running all three.

## postconditions
- Per-task result files in `results/`.

## verification
- Reproduced curves match the published figures (e.g. "Latest Models on Repeated Words Task").

## failure/recovery
- Curves don't match → check model versions + input-length grid + judge prompt; the paper pins all three.

## implementation
Python scripts per experiment; provider APIs; LLM-judge (GPT-4.1) for scoring. Paired with S20 (the report + claims).
