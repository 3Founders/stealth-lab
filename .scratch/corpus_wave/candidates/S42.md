# S42 — Retrieve a paper and its citation context from Semantic Scholar

- **Source:** semanticscholar.org — Academic Graph API docs at `api.semanticscholar.org/api-docs`
- **License:** S2 data under **ODC-BY-1.0**; API key for elevated rate limits.
- **Confidence:** medium — endpoint paths confirmed from the api-docs page.

## problem
You need a paper's metadata plus who cites it / what it cites, resolved from a DOI or arXiv id, without scraping.

## goal
Fetch a paper + its citation/reference lists with only the fields you need, respecting rate limits.

## preconditions
- A paper identifier (DOI, arXiv id, or S2 id); optionally an API key.

## steps
1. Resolve the id form (DOI: `DOI:10...`, arXiv: `arXiv:2401.00001`, or the S2 `paperId`).
2. `GET /graph/v1/paper/{id}?fields=title,year,authors,citationCount,citations.title,references.title,tldr` — request only needed fields.
3. Page `citations` / `references` with `offset` + `limit`.
4. For many ids at once: `POST /graph/v1/paper/batch` with `{"ids":[...]}` + a `fields` query param.
5. Read rate-limit headers; back off on 429.

## decision points
- >~10 ids → use the batch endpoint, not N single calls.
- Only need a summary → request `tldr` and skip the full lists.

## postconditions
- JSON with the paper's metadata and the requested citation/reference context.

## verification
- HTTP 200; `citationCount` roughly matches the length of a fully-paged `citations` list; batch order matches input order.

## failure/recovery
- 429 without a key → add an API key or slow down; anonymous limits are low.

## implementation
Plain HTTPS; field selection + pagination + batch. Deterministic. Provider: any HTTP client.
