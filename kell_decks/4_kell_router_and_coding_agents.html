Where it works

Three places, one shared memory.

AI assistants

Claude on the web and the assistant room on the kell website. kell does the delegated steps and sends back a result and a short cost note.

Coding tools

Claude Code and Cursor, through kell's add-on. It looks up a method, tries cheaper models first, and reports test results.

The kell MCP server

MCP is the standard way AI assistants reach outside tools. kell's library, record of results, choosing and spending limits sit behind it.

The kell MCP server

One connection that looks up, recommends, hands off and records.

1

Look up

Finds a way of doing this kind of task that has worked before, and when it applies.

2

Recommend

Suggests the cheapest models that are likely to get it right, in the order to try them.

3

Hand off

Runs the routine steps on lower-cost models. The hard thinking stays with the best one.

4

Record

Stores whether it passed, what it cost and how long it took, so the next choice is better.

MCP is the standard way AI assistants and coding tools connect to outside tools. Sign-in, each organisation's rules and spending limits apply to every call.

→

→

Coding agent

Claude Code, Cursor

You give the agent a coding task.

→

kell suggests a method and cheaper models to try first.

→

Tests check the answer; kell steps in with the best model only if needed.

→

The outcome is reported back.

Both lanes report what happened to the same shared memory, so every task makes the next choice better.
