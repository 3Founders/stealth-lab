The right model, and a proven way, for every task.

An MCP server that finds a way that worked, hands the routine parts to cheaper models, and checks the result.

The kell MCP · October 2026

The problem

One premium model does everything, and forgets what worked.

Every task starts from zero

The assistant re-invents the approach each time, even for work done well before.

Small jobs use the dearest model

Summaries, reformatting and first drafts cost the same as the hardest reasoning.

No record of what passed

Nobody can say which approach worked, so good methods are not reused.

What kell is

A server your assistant calls. It brings knowledge, delegation and proof.

Knowledge

A library of goals and the ways that reached them, each with its conditions and its record.

Delegation

Evidence

The library

Goals, claims, procedures and evidence.

Goals

What is to be done and how success is checked. Specific goals sit under broader ones, so evidence adds up.

Claims

Small checkable statements with their source and when they were true.

Procedures

Step-by-step ways to reach a goal, with the conditions where each applies.

Evidence

Pass or fail for every reuse. A way that stops working loses trust and is retired.

Routing

Narrow the choice in layers.

1

Goal

Match the request to a goal, using broader goals when none is exact.

2

Fit

Rule out any procedure whose conditions are not met.

3

Rank

Prefer the ones with the best record and lowest cost.

4

Model

For each step, pick the cheapest ladder that meets the reliability target.

5

Fallback

If a try fails its check, move to the next rung or endpoint.

After every task

A receipt: task done by kell, and what it cost.

What it shows

Which steps kell handled, which model answered, and the cost of the task.

How it is labelled

Compared with the same task on the reference model, shown as an API-equivalent cost, not a promise.

Where it appears

As plain text in the reply, so it works in any assistant that can call tools.

Status: planned. Budgets, a stop switch and a per-call ledger are built.
